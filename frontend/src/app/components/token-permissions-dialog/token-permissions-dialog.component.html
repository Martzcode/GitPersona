Autorisations du token GitHub

Deux types de tokens sont acceptés dans les paramètres. Voici ce dont l'application a besoin selon le type choisi.

Token classic (ghp_…)

  • Lecture seule
    Aucun scope requis

    Recherche de profils, consultation des profils publics, liste de vos followers et following.

  • Écriture
    user:follow

    Nécessaire pour suivre ou ne plus suivre quelqu'un depuis les vues Followers, Following et Management.

  • À éviter
    repo

    Donne accès à tous vos dépôts privés : inutile pour GitPersona.

Fine-grained (github_pat_…)

  • Lecture seule
    Account permissions → Followers → Read

    Suffisant pour toutes les vues en lecture.

  • Écriture
    Account permissions → Followers → Read and write

    Pour les actions Suivre / Ne plus suivre.

Sans le droit d'écriture, les boutons Suivre / Ne plus suivre renverront une erreur refusée par GitHub.
